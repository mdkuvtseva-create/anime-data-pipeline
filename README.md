# ETL-процесс для базы данных Аниме

## О чём проект
Это мой итоговый проект по курсу «Инженер данных». 
Взяла открытый датасет с аниме (база MyAnimeList), который состоял из 7 разрозненных CSV-файлов (основная таблица, жанры, персонажи, компании, актёры озвучки и т.д.). 
Задача была собрать из этого хаоса одну чистую, готовую к анализу таблицу.

## Что делает скрипт (`anime_etl.py`)
1. **Загрузка:** ищет все 7 CSV-файлов в папке `data` и читает их. (Написала функцию, которая перебирает кодировки, потому что один из файлов не хотел читаться в стандартной).
2. **Очистка:** убирает дубликаты по `anime_id`, вычищает мусор из числовых колонок (там были строки типа "8.5" и "1,234").
3. **Объединение:** самое сложное. Сначала пыталась просто джойнить таблицы, но поняла, что для связей «многие ко многим» (жанры, компании) нужно сначала сгруппировать их через `groupby`. 
4. **Сохранение:** сохраняет итог в трёх форматах: CSV, Excel и базу данных SQLite. Для Excel пришлось использовать параметр `quoting=1`, потому что иначе он ломался на кавычках в тексте.

## С какими трудностями столкнулась
- В файле `anime_voice_actors.csv` не оказалось колонки `anime_id` (она называется иначе), поэтому скрипт выдаёт WARNING и просто ставит туда нули. Не стала хардкодить переименование, оставила как есть, чтобы скрипт не падал с ошибкой.
- Сборка таблицы с персонажами заняла много времени, пришлось использовать агрегацию `size()`.

## Как запустить
1. Установите зависимости: `pip install pandas numpy openpyxl`
2. Положите все 7 исходных CSV-файлов в папку `data/`
3. Запустите скрипт: `python anime_etl.py`
4. Результаты появятся в папке `output/` (файлы `anime_clean_data_v3.csv`, `anime_clean_data_v3.xlsx` и `anime_database.db`).
